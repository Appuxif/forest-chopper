# Audio cutter

Откройте `index.html` напрямую либо `/tools/audio-cutter/` на локальном HTTP-сервере.
Один самостоятельный HTML: выбор файла, waveform, отрезки в миллисекундах,
прослушивание, WAV PCM 16 бит и ZIP. Внешних зависимостей и загрузки на сервер нет.

Проверки WAV/ZIP, диапазонов и затухания:

```bash
node --test tools/audio-cutter/audio-cutter.test.mjs
```

Тесты используют встроенные Node-модули и Python `wave`/`zipfile` для независимой
проверки экспортированных форматов. Зависимости редактора устанавливать не нужно.
