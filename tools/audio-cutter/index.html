Обрезка аудио

Выбери файл → добавь фрагменты → уточни миллисекунды → прослушай и скачай.

Всё обрабатывается в браузере. Файл никуда не отправляется. Этот HTML можно сохранить и открывать отдельно без сервера.

Выбор нового файла сбросит текущий список фрагментов после успешной загрузки.

Выбери MP3, WAV или другой поддерживаемый браузером аудиофайл.

Потяни по волне, чтобы выделить диапазон. За края выделения можно тянуть отдельно. Для точной подстройки используй поля ниже.

Экспорт: WAV PCM 16 бит. Исходная громкость сохраняется; 0 мс отключает затухание.

После выбора файла нажми «＋ Добавить фрагмент».
