# 🌲 Forest Chopper 3D

Браузерная 3D sandbox/co-op игра про исследование процедурного леса,
сбор ресурсов, рубку деревьев и строительство лагеря. Клиент — нативные
ES-модули JavaScript + Three.js; общий сетевой мир — Python WebSocket-сервер.
Есть одиночная игра, мобильное управление и графические пресеты.

**Играть:** https://appuxif.github.io/forest-chopper/

Экспериментальный прототип: аккаунтов, постоянного личного онлайн-инвентаря,
полноценной защиты от читов и законченной кампании пока нет.

## Быстрый запуск

Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/. Сборка и Node.js для игры не нужны.
Зависимости Three.js/PeerJS загружаются через CDN, поэтому одиночный режим
означает игру без игрового сервера, а не гарантированную работу без интернета.

При открытии страницы показывается главное меню. Three.js, WebGL и фоновые
воркеры создаются после выбора режима. Настройки доступны до запуска мира;
экран загрузки ближайшего окружения держится 3–5 секунд после начала рендера.

## Локальные миры

**«Локальная игра»** открывает десять слотов. Пустой слот предлагает создать
мир со случайным seed или числом `0..999998`; занятый продолжает сохранение.
В списке видны seed, даты, статистика и координаты. Корзина удаляет только
выбранное сохранение после подтверждения.

Мир автоматически сохраняется в localStorage браузера: персонаж, инвентарь,
деревья, постройки, наземные предметы и фаза суток. Сохранения привязаны
к браузеру и origin (схеме, адресу и порту). Для резервной копии используйте
**«Экспорт JSON»**: он сохраняет все занятые слоты. **«Импорт JSON»** позволяет
выбрать слоты из архива; занятые номера заменяются после подтверждения.
Настройки, достижения и отдельный прогресс обучения/заданий в архив не входят.

Старый однослотовый ключ `forest-chopper:offline-world:v1` текущая версия
автоматически не переносит; подробности хранения — в [архитектуре](docs/ARCHITECTURE.md).
Подключение к мультиплееру не заменяет локальные миры.

## Что можно делать

- Исследовать детерминированный лес с елями и берёзами, холмами, прудами,
  озёрами, грибами и цветами. У камней есть коллизии; плавания пока нет.
- Рубить деревья: замах `Chop2` наносит удар на контактном кадре по текущему
  прицелу. После падения дерева (около 3.85 с, синхронно со звуком) доступны
  три отдельных сегмента брёвен. Брёвна и выброшенные коробки исчезают через час.
- Собирать ветки, камни и растения; лесные ресурсы восстанавливаются через
  10 минут. Хранить предметы в сумке (12 слотов, 4 быстрых слота, лимит 100 кг),
  сундуках и складах брёвен.
- Создавать инструменты, мебель и лагерные сооружения. Рецепт выдаёт предмет
  в сумку, затем его можно установить. Брёвна размещаются по полуметровой
  сетке в направлениях X/Z или вертикально. Пустое хранилище можно разобрать.
- Готовить еду возле костра и зелья возле алхимического стола; следить за
  здоровьем, голодом и выносливостью. Все три шкалы имеют по пять делений.
  Игровые сутки длятся 16 минут, голод уменьшается каждые 192 секунды.
- Прыгать, строить опоры и рампы. Падение с 3 м отнимает 2 здоровья,
  с 4 м — 3, с 5 м смертельно; опасное приземление включает ragdoll.
- После смерти возвращаться за выпавшим инвентарём по часовой метке
  на миникарте. Через пять секунд доступна кнопка «Возродиться»:
  старт или активированная кровать, 5 здоровья и 3 голода. Кровать также
  позволяет лечь; Space/прыжок поднимает из сна или ручного ragdoll.
- Играть вместе: общий лес и постройки, чат, список игроков, эмоции,
  временные метки на миникарте и общая цель — 20 деревьев.

Подробные правила, ограничения и исходники — в [каталоге механик](docs/GAME_MECHANICS_CATALOG.md).

| Действие | ПК | Телефон |
| --- | --- | --- |
| Движение / спринт | WASD / Shift | Джойстик / автоспринт |
| Осмотр | Мышь | Свайп |
| Прыжок / встать | Space | Кнопка прыжка |
| Рубить / использовать выбранный предмет | Левый клик | 🪓 |
| Камера | V | Меню ⋮ |
| Сумка / закрыть панель | I / Escape | 🎒 |
| Книга крафта | K или 📖 в сумке | 📖 в сумке |

| Взаимодействие / подбор | E | Контекстная кнопка |
| Повернуть строительное бревно | R | Кнопка поворота |
| Поднять / опустить бревно на 0.5 м | PageUp / PageDown, + / − | — |
| Сместить бревно по X/Z на 0.5 м | Alt + стрелки | — |
| Разобрать постройку | Удар выбранным топором | Выбрать топор + 🪓 |

прыжок и рубку. Джойстик появляется при касании и скрывается после отпускания.

## Графика и звук

Пресеты: Ультра / Высокий / Средний / Низкий / Пользовательский. Можно отдельно
менять разрешение рендера, FPS, дальность мира, траву, воду, освещение и тени.
MSAA включено в Ultra/High и выключено в Medium/Low; изменение требует нового
WebGL-контекста, например возврата в меню с перезагрузкой.

**«Настройки → Деревья»** редактирует процедурные ели и берёзы: профили
Low/Balanced/High, seed модели, форму, листву, цвета и бюджет треугольников.
Профили можно копировать, сбрасывать, импортировать и экспортировать JSON.
Они хранятся отдельно от миров; ID, HP и seed игрового мира сохраняются.

Панель FPS показывает Render FPS, Physics FPS (частоту основного rAF-цикла),
CPU Frame Time и GPU Frame Time, если WebGL timer queries доступны.
Это диагностика, а не фиксированный физический timestep или гарантия FPS.

**«Настройки → Звук»** содержит независимые регуляторы и прослушивание
эффектов: шаги по покрытиям, рубка, голоса, прыжки, лес и огонь. Локальное
WebAudio загружается после первого пользовательского ввода. Внизу настроек
есть отдельный экспорт JSON настроек и профилей деревьев, без данных миров.
Лицензии и авторы аудио: [ATTRIBUTION.md](assets/audio/ATTRIBUTION.md).

## Multiplayer

```sh
python3 -m pip install -r requirements.txt
python3 forest_server.py --host 127.0.0.1 --port 8765
```

Откройте **«Мультиплеер»**, укажите `ws://127.0.0.1:8765` и подключитесь.
Проверка `/status` показывает состояние сервера, не создавая игрока.
Есть история, избранные адреса и PeerJS-мост; авторитетное состояние в обоих
случаях хранит Python-сервер. Лимит — 32 персонажа, включая headless-ботов.
Общий мир сохраняется в `forest_world.json` или файле, заданном через `--save`.

Для локальной сети серверу нужен `--host 0.0.0.0`, а клиентам — LAN-адрес
компьютера. На странице HTTPS (включая GitHub Pages) нужен `wss://` через
TLS reverse proxy; обычный `ws://` блокируется браузером. Например, Caddy:

```caddyfile
forest.example.com {
    reverse_proxy 127.0.0.1:8765
}
```

DNS должен указывать на сервер; порты 80/443 должны быть доступны.
GitHub Pages обслуживает только статические файлы клиента; Python-сервер
запускается отдельно. При публикации из ветки укажите её корень `/ (root)`
в Settings → Pages.

Для headless Python-ботов: [MCP/CLI и ограничения](docs/SERVER_BOTS.md),
[инструкция игровому LLM](docs/AI_PLAYER.md).

## Разработка и проверки

Из корня проекта:

```sh
node --test tests/*.test.mjs
python3 -m unittest discover -s tests -v
python3 -m py_compile forest_server.py server_bots.py bot_gateway.py bot_mcp.py bot_cli.py
for f in src/*.js; do node --check "$f" || exit 1; done
git diff --check
```

Для браузерной отладки откройте собственную вкладку `index_debug.html`:
`window.__gameDebug` появляется после входа в мир. Обычный `index.html`
его не экспортирует. Подробности — [AI_PLAYER_DEBUG.md](docs/AI_PLAYER_DEBUG.md).

Оба entrypoint поддерживают URL-параметры:

```text
?type=continue&performance=low&diag=true
?type=new&seed=123&performance=low&diag=true
?type=multiplayer&server=ws%3A%2F%2F127.0.0.1%3A8765&name=woodpecker
```

`continue` открывает первый валидный занятый слот, а `new` выбирает слот 1.
`force=true` пропускает подтверждение его замены: используйте его только
в изолированном тестовом контексте. URL-пресеты: `low|medium|high`;
`diag=true|false` управляет диагностикой, `name` — именем игрока.
Эти параметры могут сохранять настройки браузера. Для визуальных изменений
проверяйте desktop/mobile и консоль; для сетевых тестов запускайте отдельный
сервер с уникальным временным `--save`, сохраняя пользовательский мир.

### Курицы и охота

В лесу встречаются небольшие группы куриц; несколько появляются рядом со стартом.
Они гуляют, отдыхают, клюют землю (случайно один, два или три раза) и убегают
от приближающегося игрока. Бег курицы — 3,6 м/с (снижен на 20%); игрок на спринте заметно быстрее.
При начале настоящего бегства курица один раз кричит, затем часто издаёт
случайные короткие кудахтанья. В покое — редкие серии по 2–4 звука.
Бег к стае без паники не вызывает крик; при смертельном попадании топора один раз звучит `07_hen_death.wav`, затем новые реплики прекращаются.
Крики, кудахтанье и звук смерти имеют отдельные ползунки в настройках звука и затихают
с расстоянием (до 14 м). При столкновении курица выбирает случайный свободный поворот и некоторое время держит его. Это простой манёвр, без поиска пути.

Один контактный удар выбранным топором с расстояния до 2,6 м убивает курицу
и включает физическое падение. При точном наведении на живого моба в пределах
удара перекрестие сразу меняется на красное: цель проверяется каждый кадр,
тем же результатом пользуется контактный удар. Во время спринта за живым
мобом в центре экрана до 10 м соседние предметы не окрашивают прицел в зелёный:
при неточном наведении он нейтрален, при точном в пределах удара — красный.
После остановки или отвода взгляда обычные подсказки возвращаются. Наведитесь на тело в пределах 2,8 м и нажмите E на подсказке «Курица · Открыть»: окно рядом с ним позволяет забрать
**1–3 мяса и 1–5 перьев**. На телефоне используйте контекстную кнопку подбора.
Пустое тело остаётся до истечения часа от смерти; новая курица появляется
через три игровых дня (48 минут движения часов мира). В одиночной игре этот
таймер не идёт при закрытом мире или выключенном цикле суток.

Сырое мясо восстанавливает 1 голод. В книге крафта, вкладка еды, возле костра
(до 10 м) доступны по одной порции:

- **Жареная курица:** 1 мясо → +2 голода.
- **Курица с грибами:** 1 мясо + 1 боровик → +3 голода (груздь не подходит).
- **Курица с травами:** 1 мясо + 1 синий цветок → +2 здоровья и +2 голода.

Перья пока можно только хранить и переносить. В online животных, смерть и
выдачу добычи контролирует сервер; для новых механик нужен обновлённый сервер.

В окне добычи курицы предметы расположены строками: колесо выбирает строку,
**E** забирает выбранный предмет, **R** — всё. Пока окно открыто, E не подбирает
ресурсы с земли. При захваченной мыши наведите игровое перекрестие на строку,
«Забрать всё» или «Закрыть» и нажмите ЛКМ. Элемент подсвечивается; над любой
частью окна нажатие не запускает удар. Перекрестие отображается поверх окна. Карточка расположена над тушкой,
чтобы нижние кнопки были доступны вблизи при взгляде вниз.
Клик обычным курсором и тап тоже работают.
Окно не освобождает мышь автоматически: нажмите **Esc**, чтобы вернуть курсор,
при этом окно остаётся открытым. Удар слегка отбрасывает тушку от игрока,
сохраняя часть инерции бега. Rapier/WASM заранее готовится при входе в мир,
вместо загрузки при первом ragdoll персонажа или курицы.

Окно тушки открывается только по E на подсказке «Курица · Открыть», автоматически
не появляется. После последнего предмета окно закрывается; в online — по
обновлённому состоянию сервера. Пустая тушка показывает «Курица · Пусто» и не
открывается. E, клик и тап используют общий перенос и одинаковое предупреждение
«В сумке нет места». Стандартный звук pickup звучит только при успешном
получении добычи (online — после подтверждения сервера). Суставы шеи и ног
имеют ограниченные углы и упругость; голова сталкивается с корпусом. Наведение,
дистанция открытия и локальный подбор следуют за физической тушкой, включая
сохранённую позу после загрузки мира.

### Общая система мобов

Курица теперь является типом общего мира мобов. Категория — `chicken`,
подкатегории окраски — russet, white, black, golden, speckled; окрас выбирается
по seed/ID, сохраняется и синхронизируется. AI, характеристики, модель/анимации,
физический профиль и добыча задаются отдельно. Новые враги и PvP не включены.
Описание расширения и совместимости: [Мобы](docs/MOBS.md).

В `index_debug.html` откройте «🎮 Читы → 🐔 Тестовые мобы · Курица»:
выберите окрас и количество (1–8), нажмите «Создать курицу». Спавн ищет
безопасное место перед игроком; тестовые мобы не сохраняются и доступны
только offline. «Удалить тестовых мобов» не удаляет обычную популяцию.
Окно читов закрывается кнопкой «Закрыть ×» справа в шапке над прокручиваемым списком.

Центр стаи на 50% зависит от текущих позиций живых куриц, на 50% — от их
исходных точек спавна. Так стая сохраняет подвижность и не уходит бесконечно
далеко при спокойном блуждании. Даже последняя выжившая курица сохраняет
привязку к месту появления. Куры гуляют случайно,
а отставшие подтягиваются, при большом разрыве — бегом. Бегство от игрока и
проверка коллизий важнее притяжения к стае. Несколько куриц, созданных одним
нажатием чит-кнопки, также образуют одну тестовую стайку.

Во время игры Ctrl+R/Cmd+R блокирует перезагрузку через доставленный странице
keydown; обычные R/W продолжают работать. Ctrl+W/Cmd+W в обычной вкладке может
перехватываться браузером раньше игры. Для защиты от этих сочетаний включите
«⛶ Полный экран» в главном меню: при поддержке Keyboard Lock игра запрашивает
захват только R/W. При отказе или отсутствии API остаётся предупреждение о
закрытии/перезагрузке; полная блокировка Ctrl+W не гарантируется. Esc не
захватывается, намеренный выход в меню освобождает клавиатуру.

### Локальный редактор аудио

Откройте [`tools/audio-cutter/`](tools/audio-cutter/): выберите исходный
аудиофайл и нажмите «＋ Добавить фрагмент». У каждого отрезка есть имя,
границы «От/До» в миллисекундах, подстройка ±10 мс и прослушивание.
Границы можно перетаскивать на волне. Экспорт — отдельные WAV PCM 16 бит
или все отрезки одним ZIP; стереоканалы сохраняются. Затухание краёв
настраивается, 0 мс отключает его. Файл обрабатывается в браузере без
отправки на сервер. Редактор не запускает игру и работает как отдельный HTML
без внешних библиотек. Выбор другого файла сбрасывает список отрезков.
