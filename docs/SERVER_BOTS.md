# Headless AI bots — быстрый MVP

**Инструкция для LLM-агента:** [AI_PLAYER.md](AI_PLAYER.md). **Браузерный дебаг:** [AI_PLAYER_DEBUG.md](AI_PLAYER_DEBUG.md).

В браузере и `index_debug.html` **ничего менять не нужно**: люди и AI через Chrome DevTools продолжают играть как раньше. Серверные боты — ещё один тип игрока: живут внутри `forest_server.py`, без вкладок/Three.js и управляются отдельным MCP/CLI по `/bots` на том же WebSocket-порту.

## Запуск за минуту

```bash
# Терминал 1: центральный сервер (перезапустить после обновления кода)
pip install -r requirements.txt
python3 forest_server.py --host 127.0.0.1

# Терминал 2: отдельный CLI для теста без LLM
python3 bot_cli.py 'Bot Vasya'
```

В интерактивном CLI: `observe`, `status`, `follow 1`, `stop`, `harvest 5`, `goto 10 10`, `chop 0,-1:1`, `say Привет!`, `quit`. ID игрока смотри через `observe`. Открой игру по обычному адресу, подключись к `ws://localhost:8765`: бот должен появиться как удалённый игрок с именем над головой и точкой на миникарте.

## MCP-сервер отдельно от игры

```bash
pip install -r requirements-bot-mcp.txt
python3 bot_mcp.py
```

По умолчанию запускается **MCP stdio**, подходящий для локального Codex/Claude и других MCP-клиентов. Укажите в конфигурации клиента команду `python3 /absolute/path/to/forest-chopper/bot_mcp.py`, рабочую директорию и, если нужно, переменные окружения. Для доверенного HTTP-тестирования MCP SDK также умеет `FOREST_MCP_TRANSPORT=streamable-http`; **не публикуйте этот endpoint в интернет без настоящей авторизации**. Для подключения ChatGPT через удалённый MCP потребуются соответствующая сетевая доступность и авторизация/OAuth-прокси — в MVP они не реализованы.

**Сценарий агента:**

1. `register_agent(session_id="thread-a", name="Вася")` — создать бота и получить его игровой ID.
2. `observe(session_id="thread-a")` — получить ближайшие деревья и игроков.
3. `start_following(session_id="thread-a", player_id=1)` — следовать за человеком до команды `stop_following`.
4. `harvest(session_id="thread-a", wood=50)` — автономно добывать древесину до **общего запаса** 50.
5. `get_brief(session_id="thread-a", after_chat_id=0)` — компактный статус и новые сообщения.
6. `say(session_id="thread-a", text="Принял!")`, `stop(session_id="thread-a")`, `remove_agent(session_id="thread-a")`.

Также доступны `start_task` (типы `navigate`, `followPlayer`, `chopTree`, `harvest`, `move`), `navigate_to`, `chop_tree`, `get_task`. Все длительные действия фоновые: команды быстро возвращают ID задачи. **Одна активная задача на бота.** Следование бессрочно, пока не выключено.

**Многосессионность:** один процесс MCP обслуживает несколько `session_id`, каждому соответствует отдельный WebSocket и игровой персонаж. Прототип рассчитан на **доверенный MCP-хост**: `session_id` — маршрутизатор, **не доказательство личности**. Не отдавайте общий MCP публично незнакомым агентам; для строгой изоляции потребуются аутентифицированные principals/персональные ключи и привязка к MCP-сессии. Сервер поддерживает до 32 персонажей вместе с браузерными игроками.

## Удалённый сервер

```bash
# На центральном сервере (задайте достаточно длинный случайный секрет):
export FOREST_BOT_TOKEN='your-long-private-token'
python3 forest_server.py --host 0.0.0.0

# На компьютере, где работает отдельный MCP:
export FOREST_GAME_URL='wss://your-host/bots'
export FOREST_BOT_TOKEN='your-long-private-token'
python3 bot_mcp.py
```

Проксируйте WSS через TLS. Если `FOREST_BOT_TOKEN` не задан, подключения к `/bots` проверяются по loopback-адресу. **При обратном прокси (Cloudflare, nginx и т.п.) это не защита: удалённый запрос может выглядеть как локальный. Всегда задавайте токен при публикации `/bots` наружу.** Обычным браузерным WebSocket-подключениям токен не требуется.

## Что упрощено намеренно

- Серверные боты ходят только по земле (`y=0`), используют 2D-коллизии деревьев и доступных по высоте брёвен. Прыжки и лестницы пока не реализованы.
- Для обхода препятствий — простой выбор направления с несколькими отклонениями, **не A\***. На сложных постройках бот может застрять, `blocked` показывает результат. `harvest` пробует другое дерево.
- Сервер теперь проверяет горизонтальные коллизии и у обычных игроков при получении движения, но полноценной серверной гравитации, предсказания и отката позиции нет.
- MCP-соединение держит бота живым. При отключении или закрытии MCP-сессии бот исчезает из мира (новое подключение создаст нового бота); постоянное хранение ботов и восстановление владельца не реализованы.
- Jev и LLM-worker **не интегрированы**: их позже можно поставить *над* тем же MCP, не меняя игровой сервер.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют временный игровой мир и случайный локальный порт: существующую игру и `forest_world.json` не меняют.
